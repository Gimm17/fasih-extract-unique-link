Halaman 1

Buat proyek

Satu proyek per survei/periode untuk mencegah inventaris tumpang tindih. URL, pencarian, urutan dan filter harus sama pada semua komputer.

Perubahan URL/cakupan hanya sebelum inventaris atau setelah reset pusat.

Tambah komputer

Buat satu token berbeda untuk setiap komputer. Komputer Koordinator mengirim inventaris awal dan juga dapat mengerjakan tugas.

Token tampil sekali.

Masukkan ke Pengaturan server pada ekstensi komputer terkait.
Urutan menjalankan 5 komputer
  1. Buat proyek dan 5 token; satu berperan Koordinator.
  2. Unduh ZIP ekstensi melalui tombol di atas, ekstrak, lalu pasang melalui chrome://extensions → Developer mode → Load unpacked. Untuk pembaruan, pilih folder terbaru lalu muat ulang tab FASIH.
  3. Hubungkan ekstensi masing-masing komputer.
  4. Koordinator klik Inventaris ke server; tunggu proyek Siap.
  5. Kelima komputer klik Mulai tugas server.
  6. Pantau hasil dan unduh Excel gabungan.

Target inventaris

Jika jumlah kartu berbeda dari target, periksa filter sebelum menyesuaikan angka. Nilai 0 menerima jumlah hasil inventaris.

Ubah password admin

Reset data pusat proyek

Hasil, link, inventaris, dan riwayat proyek aktif akan dihapus. Token komputer tetap ada. Hentikan semua komputer, sinkronkan hasil lokal, lalu tunggu kunci berakhir. Reset ditolak selama ada kunci aktif.
