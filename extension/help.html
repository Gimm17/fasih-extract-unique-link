5 komputer dengan server

  1. Pasang paket server PHP/MySQL sesuai INSTALL.md pada fulx.pinnhost.my.id.
  2. Buat satu proyek dan 5 token berbeda, satu berperan Koordinator inventaris.
  3. Login FASIH pada setiap komputer. Samakan URL, filter, pencarian dan urutan data.
  4. Panel → Pengaturan server → masukkan https://fulx.pinnhost.my.id/api.php dan token komputer masing-masing.
  5. Aktifkan mode wilayah Kota Palu pada proyek lama; hasil tetap disimpan. Koordinator klik Inventaris ke server: ekstensi menemukan kecamatan/desa lalu memasang filter satu per satu. Tunggu dashboard menunjukkan Siap dan jumlah benar.
  6. Kelima komputer klik Mulai tugas server. Server membagi desa/partisi yang berbeda, memasang filter wilayah yang sama, dan menyimpan hasil pusat.
  7. Dashboard diperbarui tiap 3 detik. Unduh Excel gabungan pada Data & hasil.

Inventaris dimiliki Koordinator lain: lihat nama dan ID pemilik di Kelola proyek/Monitor pekerjaan. Gunakan token pemilik untuk melanjutkan. Jika berganti Koordinator, hentikan proses lama dan nonaktifkan token pemilik; Koordinator aktif bisa melanjutkan inventaris tanpa reset. Data dan link tersimpan dipertahankan. Status OFFLINE saja tidak melepaskan kepemilikan.

Koneksi putus: gunakan proses/token komputer yang sama, Sinkronkan hasil tertunda, lalu Lanjutkan. Paket kedaluwarsa masuk Perlu pemeriksaan; tidak langsung diambil komputer lain. Jika pemilik hilang, pastikan sudah berhenti dan kunci berakhir sebelum admin mengantrikan ulang paket.

Coba ulang gagal pada panel mengaktifkan data ERROR milik komputer; tombol dashboard mengaktifkan ERROR pada paket yang sudah ditutup. DONE dan link tersimpan dipertahankan.

Batas 1.000 FASIH

Inventaris dan ekstraksi server berjalan per desa. Opsi - dilewati. Jika desa mencapai 1.000 kartu, lanjut per SLS; jika SLS mencapai 1.000, lanjut per SUBSLS. Di bawah batas, dropdown anak tidak dibuka dan filter anak lama dikosongkan melalui X. SUBSLS yang tetap mencapai 1.000 atau daftar anak valid kosong menyebabkan jeda; inventaris belum dianggap lengkap. Dashboard Progres wilayah memantau rekap desa/kecamatan/kota. Target Kota Palu tetap 11.649 dan awalan 7271. Pembaruan hosting: ikuti UPDATE_WILAYAH.md, Git pull, lalu migrasi tanpa reset database.

Mode lokal

Saat server tidak terhubung, Cek data halaman memeriksa kartu, Pilot 5 data menguji alur, dan Mulai seluruh data pada filter menjalankan inventaris serta ekstraksi. Mode lokal diblokir saat server terhubung agar pembagian tugas tetap terkontrol.

Alur: titik tiga → Pengaturan Email → Dapatkan Unique Link jika diperlukan → simpan URL lengkap → tutup popup. URL dibaca langsung, tanpa klik Copy. Mode hanya dibaca; pengiriman email/pesan tidak dijalankan. Kolom opsional yang tidak tampil boleh kosong.

Jeda aksi default 0,50 detik; antar data 1,00 detik. Ubah di panel lalu Simpan jeda saat proses berhenti. Nilai berlaku pada mulai/lanjut/ulang gagal. FASIH yang belum siap dapat menambah waktu tunggu.

Biarkan tab FASIH aktif. Navigasi halaman otomatis. Reload yang tidak direncanakan membutuhkan Lanjutkan. Perubahan isi/filter halaman menjeda proses.

Reset full menghapus progres, hasil, koneksi server dan pengaturan lokal; sinkronkan hasil tertunda dahulu. Reset pusat tersedia terpisah di dashboard dan memerlukan konfirmasi nama proyek serta tidak ada kunci aktif. Data FASIH dan file unduhan tidak dihapus.
